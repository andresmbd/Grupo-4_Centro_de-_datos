# 📄 Data Center Control – MVP Documentation

## 📌 1. Project Overview

Data Center Control is a simulation-based monitoring system designed to manage the operational balance between infrastructure resources and business demand inside a Data Center.
The system simulates the interaction between:
Server infrastructure
Cooling systems
Customer demand
The goal is to prevent infrastructure failures, maintain service stability, and optimize resource utilization.
The simulator evaluates system conditions such as:
Server temperature
Server capacity
Customer demand
System stability
This MVP demonstrates the core operational logic of a data center management system.

## 🎯 2. MVP Objective
The goal of the Minimum Viable Product (MVP) is to implement a basic simulation capable of:
Monitoring server temperature
Detecting critical temperature levels
Managing server capacity vs customer demand
Simulating service degradation when demand exceeds capacity
Applying business rules to maintain system stability
The MVP focuses on demonstrating core operational logic rather than full production functionality.

## 🧠 6. Business Logic & Operational Rules
The simulator operates under the following core business rules.

🔥 Temperature Control
If the system detects a temperature above 80°C, servers are automatically marked as damaged.
Temperature > 80°C → Server Failure
This simulates hardware overheating in real data centers.

⚙️ Resource Management
The system continuously monitors the relationship between:
Server Capacity
Cooling System Efficiency
Customer Demand
Improper balance between these variables may lead to:
System instability
Performance degradation
Hardware damage

📈 Scalability & Demand Handling
If customer demand exceeds server capacity, the system will experience:
Reduced performance
Service instability
Possible service interruption
This simulates real-world capacity bottlenecks in data centers.

## 🔄 9. System Simulation Flow
The system simulation follows this process:
1️⃣ The system initializes server infrastructure and cooling parameters.
2️⃣ A customer demand value is generated by the demand simulator.
3️⃣ The system checks server capacity vs incoming demand.
4️⃣ The temperature monitor evaluates system temperature.
5️⃣ If temperature exceeds 80°C, the server is marked as damaged.
6️⃣ The stability controller evaluates system status and reports:
Stable
Warning
Critical
