# Data Center Control 🗄️ - Group 4️⃣

## Description 📝
This project is a simulation and control system for the management of a Data Center.  
The application simulates the critical balance between physical infrastructure and business demand.

## Business Logic & Rules 🧠
For the simulator to function correctly, the following rules must be followed:

- **Critical Temperature:** If the system detects a temperature above **80°C**, the servers are automatically damaged.
- **Resource Management:** The relationship between **Server Capacity, Cooling System, and User Demand** must be constantly monitored.
- **Scalability:** If customer demand exceeds the current capacity of the servers, the system will experience a loss of service quality or stability.
- **Programming Rules:** The program must use **structured programming only** (functions, loops, and conditionals).  
  Each function must follow the **Single Responsibility Principle**.
